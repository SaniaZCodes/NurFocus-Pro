# 🎯 NurFocus Pro | Command Center

**NurFocus Pro** is a high-performance productivity dashboard designed for deep work sessions. It combines a smart Pomodoro timer with a priority-based Kanban board to help developers and students conquer their missions.

## 🚀 Key Features

* **⚡ Dual-Vibe Themes**:Instantly switch between "Studio Dark" for night coding and "Clean Alpine" light mode for morning focus via the settings gear.
* **🛠️ Kanban Management**: Organize missions into High, Medium, and Low priority columns.
* **⏲️ Advanced Timer**: Custom Pomodoro logic that automatically handles breaks for long sessions.
* **💾 Local Intelligence**: All your tasks and theme preferences are saved in your browser (LocalStorage)—no database needed.
* **📱 Tactile UI**: Smooth animations and physical button-press effects for a premium feel.

---

## 🛠️ Built With

* **HTML5 Semantics**: Structured for accessibility and clean SEO.
* **CSS3 (Custom Variables)**: Powerful theme engine using CSS `:root` and transitions.
* **Vanilla JavaScript**: Optimized DOM manipulation and state management.
* **Google Fonts**: "Plus Jakarta Sans" for that modern tech look.

## ⚙️ Installation & Usage

1.  **Clone the Repository**:
    ```bash
    git clone [https://github.com/YOUR_USERNAME/nurfocus-pro.git](https://github.com/YOUR_USERNAME/nurfocus-pro.git)
    ```
2.  **Open the App**:
    Just open the `index.html` file in any modern browser.

3.  **How to use**:
    * Add a mission and select its priority.
    * Click **🎯 Focus Mission** on a card to load it into the timer.
    * Hit the **⚙️ Gear Icon** in the header if you want to change the theme.
    * Start the timer and get to work!
